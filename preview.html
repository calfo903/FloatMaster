Architecture — WindowManager over Freeform

 Presentation (Compose M3)
 ┌─────────────────────────────────────────────────────┐
 │ MainActivity → Onboarding → Home (Mini Apps / Active / Settings) │
 │ WindowChrome (drag, resize, alpha, border, z-order) · BubbleView · FloatingDock │
 └──────────────────────┬──────────────────────────────┘
                        │ StateFlow<FloatingWindow>
 Domain                  ▼
 ┌─────────────────────────────────────────────────────┐
 │ FloatingWindowManager (singleton, single source of truth) │
 │ WindowController · WindowHistoryManager · UseCases   │
 └──────────────────────┬──────────────────────────────┘
                        │ addView / updateViewLayout / removeView
 Data                    ▼
 ┌─────────────────────────────────────────────────────┐
 │ Room (Notes) · DataStore (settings, history, clipboard) · Retrofit (Translator) │
 └──────────────────────┬──────────────────────────────┘
 System                  ▼
 ┌─────────────────────────────────────────────────────┐
 │ FloatingService (FG service, specialUse, START_STICKY) │
 │ WindowManager.TYPE_APPLICATION_OVERLAY  ←  ComposeView + WebView + PdfRenderer │
 │ KeepAliveService · BootReceiver · AccessibilityService (optional) │
 └─────────────────────────────────────────────────────┘

Why not freeform? Freeform is only reliable on 12L+ tablets/DeX. TYPE_APPLICATION_OVERLAY works on every OEM back to Android 8. ComposeView is hosted inside a FrameLayout added via WindowManager.addView() with a custom LifecycleOwner so recomposition works inside the Service.

SYSTEM_ALERT_WINDOW Flow

1. Onboarding checks Settings.canDrawOverlays()

2. If false → ACTION_MANAGE_OVERLAY_PERMISSION with package URI + OEM guide (Xiaomi/Oppo/Samsung/Huawei steps).

3. Also requests POST_NOTIFICATIONS (13+) and battery whitelist via BatteryOptimizationHelper.

4. Once granted → FloatingService.start() → startForeground() with specialUse type (Android 14+).

Focus: FLAG_NOT_FOCUSABLE by default → tap title bar clears flag → keyboard shows → outside tap re-adds flag.

OEM & Play Store Notes

  • Xiaomi/ColorOS/Vivo/Huawei/Samsung — deep-link to autostart screens; whitelist instructions per OEM string.
  • QUERY_ALL_PACKAGES — avoided; use <queries> with LAUNCHER intent (Play rejects otherwise).
  • Accessibility — optional, disclosure + video required if declared.
  • FGS type — specialUse + property for Android 14.
  • Storage — scoped storage, SAF, READ_MEDIA_*.
